### Stock-Market-Analytics-Dashboard

This README provides business-focused analysis, key insights, and metrics definitions for the dashboards included in this repository. The goal is to help hiring managers, recruiters, and collaborators understand analytical thinking, KPI design, and impact-driven approach as a Business Analyst.

#Objective:

To evaluate stock performance, identify market trends, analyze portfolio risk, and support investment decision‑making.


#Key Metrics & KPIs:

>Price Trend & Volume Trend

>SMA / EMA (Moving Averages)

>Volatility Index (σ)

>Sector Performance Comparison

>Portfolio Return %, Sharpe Ratio

>Correlation Matrix (Stock Interdependencies)


 #Insights Provided:

>Detected bullish/bearish trends using 50‑day and 200‑day SMA crossover.

>Sector‑wise heatmap showed strong performance in technology & finance.

>Correlation matrix identified diversification weaknesses.

>Portfolio return and risk analysis helped rebalance allocations.


#Business Impact:

>Enables data-driven investment decisions.

>Improves portfolio risk management.

>Helps investors track market signals and react early.


#How to Use These Dashboards:

1.Open the .twb / .twbx files using Tableau Desktop or Tableau Public.

2.Review metrics & insights listed above while exploring the dashboard.

3.Use the dashboards to extract business insights and re-run analysis with updated data.
